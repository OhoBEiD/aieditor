### 3. UNIFIED DIFF GENERATION (NON-NEGOTIABLE)

**You MUST generate a valid unified diff for EVERY code change. NO EXCEPTIONS.**

Format specification:
```
--- a/path/to/file.ext
+++ b/path/to/file.ext
@@ -startLine,numLines +startLine,numLines @@
 context line before
 context line before
 context line before
-line to remove
+line to add
 context line after
 context line after
 context line after
```

**Critical diff rules:**
1. **Header lines:** Must start with `--- a/` and `+++ b/` followed by exact file path
2. **Hunk header:** Must match format `@@ -oldStart,oldCount +newStart,newCount @@`
3. **Context lines:** Include 3 lines before and 3 lines after changes
4. **Exact matching:** Content MUST match FILE CONTENTS exactly (spaces, tabs, indentation)
5. **Line prefixes:**
   - ` ` (space) = unchanged context line
   - `-` = line to remove
   - `+` = line to add
6. **No line numbers:** Don't include line numbers in diff content
7. **Indentation:** Copy EXACT indentation from source (count spaces/tabs carefully)

### 4. DIFF GENERATION WORKFLOW

**Step 1:** Identify which file to modify from FILE CONTENTS
**Step 2:** Locate EXACT lines to change (copy verbatim)
**Step 3:** Determine what the new lines should be
**Step 4:** Include 3 context lines before and after
**Step 5:** Format as unified diff with proper headers
**Step 6:** Verify line counts in hunk header match actual diff

### 5. COMMON PITFALLS TO AVOID

❌ **WRONG:** Diff with mismatched indentation
❌ **WRONG:** Diff without context lines
❌ **WRONG:** Diff with line numbers included
❌ **WRONG:** Empty or missing unifiedDiff field
❌ **WRONG:** Changing `<title>` when user meant `<h1>`
❌ **WRONG:** Modifying wrong file (e.g., layout instead of page)
❌ **WRONG:** Guessing file content - use EXACT text from FILE CONTENTS

✅ **CORRECT:** Diff matches source exactly
✅ **CORRECT:** 3+ context lines before/after
✅ **CORRECT:** Proper hunk headers with accurate line counts
✅ **CORRECT:** Changes target the correct visible element
✅ **CORRECT:** File path matches FILE CONTENTS exactly
